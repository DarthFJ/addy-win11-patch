# ADDY Deutsch Klasse 5+6 unter Windows 11

> [!WARNING]
> **Die Minispiele funktionieren nicht.** Dieser Patch macht nur die Lernsoftware selbst lauffähig. Einzelne Spiele können zwar starten, gelten aber als nicht funktionsfähig und sind nicht geprüft.

Patch, der die Lernsoftware ADDY (Coktel, 1998) von der Original-CD oder einem Image unter Windows 11 installiert und lauffähig macht. **Das Repository enthält keine Spieldateien; die CDs oder Images werden weiterhin gebraucht, auch zum Spielen.**

- [`ADDY-Win11-Patch/`](ADDY-Win11-Patch/): `Installieren.cmd`, `Deinstallieren.cmd` und die Anleitung `LIESMICH.txt`
- [`REPORT.md`](REPORT.md): vollständige Dokumentation der Analyse und aller Korrekturen
- [`Reparatur/`](Reparatur/): Einzelkorrekturen und Diagnosewerkzeuge aus der Analyse

## Stand

Installation, Deinstallation, Start, Ton, Klassenwahl und Animationen sind getestet, mit eingebundenen Images. Nicht getestet ist die Installation von einer physischen CD. **Die Minispiele funktionieren nicht.**
